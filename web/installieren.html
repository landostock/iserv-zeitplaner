Zwei kostenlose Konten vorbereiten.

Die Installation funktioniert vollständig im Browser. Kein Terminal, kein Downloadprogramm.

Sie benötigen ein eigenes Cloudflare-Konto und ein GitHub-Konto. GitHub bewahrt Ihre eigene Programmkopie auf; Cloudflare betreibt Ihre Website.

Warum nicht einfach beim Entwickler bleiben?

Damit der Entwickler weder Ihre PDFs noch Ihren IServ-Zugang auslesen kann, müssen Website und Ausführung vollständig in Ihrem Konto liegen. Geben Sie ihm keine Verwaltungsrechte. Prüfen Sie die Ausgangsversion und spätere Updates selbst oder mit einer Person Ihres Vertrauens.

Kostenlos innerhalb der Anbietergrenzen. Bei ausgeschöpften Kontingenten kann der Dienst ausfallen. Der Assistent bucht keinen kostenpflichtigen Tarif.

Cloudflare erstellt eine eigene Kopie im von Ihnen gewählten GitHub-Konto. Kontrollieren Sie den Kontonamen und wählen Sie einen neuen Projektnamen, zum Beispiel „mein-iserv-zeitplaner“.

  1. Die vorgeschlagenen Build- und Deploy-Einstellungen übernehmen.
  2. Bei SETUP_CODE ein selbst erzeugtes, zufälliges Passwort mit mindestens 24 Zeichen aus Ihrem Passwortmanager hinterlegen. Dort speichern; gleich wird es auf Ihrer eigenen Website benötigt.
  3. Die Installation starten und warten, bis Cloudflare „Success“ meldet.
In meinem Cloudflare-Konto installieren

Wenn Cloudflare etwas nachfragt

E-Mail bestätigen: den Link in Ihrem Postfach öffnen und dieselbe Installation fortsetzen. workers.dev-Adresse: einmalig die Kontoadresse anlegen. Name vergeben: einen anderen Namen für ein neues Projekt wählen; vorhandene Projekte nicht überschreiben. Build abgebrochen: zuerst die genaue Fehlermeldung im eigenen Dashboard prüfen, statt eine weitere Kopie anzulegen.

Öffnen Sie die feste workers.dev-Adresse aus Ihrem Cloudflare-Projekt. Dort führt Sie der private Assistent durch Passkey, Wiederherstellungscode, IServ-Verbindung und einen echten Veröffentlichungstest.

Erst auf Ihrer eigenen Adresse geben Sie den Einrichtungscode und später Ihr IServ-Passwort ein. Die öffentliche Startseite braucht diese Daten nicht.
