Konten vorbereiten

Öffnen Sie Ihre Konten bei Cloudflare und GitHub. Falls Sie noch keines haben, wählen Sie jeweils den kostenlosen Tarif.

Cloudflare ↗Betreibt Ihren ZeitplanerGitHub ↗Speichert den Programmcode
Kosten und Zugriffsrechte

Wählen Sie bei beiden Anbietern den kostenlosen Tarif. Wird ein Nutzungslimit erreicht, kann der Dienst ausfallen.

Installieren Sie den Zeitplaner in Ihren eigenen Konten und geben Sie dem Entwickler keine Verwaltungsrechte. Prüfen Sie den Programmcode und spätere Updates selbst oder lassen Sie sie von einer Person Ihres Vertrauens prüfen.

  1. GitHub verbinden
  2. Installieren
  3. Ergebnis prüfen

Öffnen Sie die Vorlage bei Cloudflare. Unter Git account → New GitHub connection verbinden Sie Ihr GitHub-Konto. Kommen Sie danach in diesen Tab zurück.

Vorlage bei Cloudflare öffnen ↗
Nach der Anmeldung erscheint „Select a repository“?

Öffnen Sie die Vorlage über diesen Link erneut. Wählen Sie dort keines Ihrer anderen Projekte aus.

Zur Zeitplaner-Vorlage ↗

Öffnen Sie die Vorlage erneut. Prüfen Sie Ihr Konto und aktivieren Sie Create private Git repository. Sie müssen nur einen Projektnamen und einen Einrichtungscode eintragen.

SETUP_CODE

Im Passwortmanager einen zufälligen Code mit mindestens 24 Zeichen erzeugen und speichern. Diesen Code nur bei Cloudflare eintragen; Sie brauchen ihn anschließend auf Ihrer eigenen Website.

Installation bei Cloudflare öffnen ↗
Welche Einstellungen soll ich lassen?

Build command: npm run build
Deploy command: npm run deploy
„Enable Preview builds“ ausschalten. „Protect with Cloudflare Access“ ausgeschaltet lassen. Den Rest übernehmen.

Projektname und Kontoadresse

Sie können auch „iserv-zeitplaner“ verwenden. Die Website-Adresse enthält zusätzlich Ihre eigene Cloudflare-Kontoadresse. Ist der Projektname bereits in Ihrem Konto belegt, wählen Sie einen anderen; überschreiben Sie keine vorhandene Installation.

Warten Sie in Cloudflare auf die erfolgreiche Bereitstellung. Öffnen Sie anschließend die dort angezeigte workers.dev-Adresse.

Cloudflare braucht noch eine Angabe

E-Mail bestätigen: den Link im Postfach öffnen und im selben Projekt fortsetzen. workers.dev-Adresse: eine Kontoadresse anlegen. Build fehlgeschlagen: die Fehlermeldung im bestehenden Projekt prüfen. Legen Sie dafür keine zweite Kopie an.

Kopieren Sie die feste workers.dev-Adresse aus Ihrem Cloudflare-Projekt hierher. Dort geht es mit Passkey und IServ-Verbindung weiter.

Die Adresse endet auf .workers.dev. Einrichtungscode und IServ-Passwort erst auf Ihrer eigenen Website eingeben.
