Konten vorbereiten

Melden Sie sich bei Cloudflare und GitHub an oder erstellen Sie dort jeweils ein kostenloses Konto. Cloudflare betreibt den Zeitplaner, GitHub speichert den Programmcode.

Kosten und Zugriffsrechte

Wählen Sie bei beiden Anbietern den kostenlosen Tarif. Wird ein Nutzungslimit erreicht, kann der Dienst ausfallen.

Installieren Sie den Zeitplaner in Ihren eigenen Konten und geben Sie dem Entwickler keine Verwaltungsrechte. Prüfen Sie den Programmcode und spätere Updates selbst oder lassen Sie sie von einer Person Ihres Vertrauens prüfen.

Öffnen Sie Cloudflare über den Button unten. Wählen Sie Ihr Konto und einen neuen Projektnamen, zum Beispiel „mein-iserv-zeitplaner“.

  1. Unter Git account auf New GitHub connection klicken und das eigene GitHub-Konto verbinden. Create private Git repository aktivieren.
  2. Die vorgeschlagenen Build- und Deploy-Einstellungen übernehmen.
  3. Im Passwortmanager einen zufälligen Code mit mindestens 24 Zeichen erzeugen und speichern. Bei SETUP_CODE eintragen. Sie brauchen ihn gleich für die Einrichtung.
  4. Die Installation starten und warten, bis Cloudflare „Success“ meldet.
Bei Cloudflare installieren

Hilfe bei der Installation

Weitere Einstellungen: „Enable Preview builds“ ausschalten und „Protect with Cloudflare Access“ ausgeschaltet lassen. MODE bleibt „production“, SELF_HOSTED bleibt „true“.

E-Mail bestätigen: den Link im Postfach öffnen und die Installation fortsetzen. workers.dev-Adresse: eine Kontoadresse anlegen. Projektname belegt: einen neuen Namen wählen; vorhandene Projekte nicht überschreiben. Build abgebrochen: die Fehlermeldung im Cloudflare-Dashboard prüfen, bevor Sie es erneut versuchen.

Kopieren Sie die feste workers.dev-Adresse aus Ihrem Cloudflare-Projekt hierher. Auf Ihrer Website richten Sie anschließend die Anmeldung und die IServ-Verbindung ein.

Einrichtungscode und IServ-Passwort erst dort eingeben.
